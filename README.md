# Сборка старого Telegram iOS (до Liquid Glass) через GitHub Actions

Неофициальный форк-сборщик. Не использует название и логотип Telegram.
Код патчей лежит в папке `patches/` (публикация нужна по лицензии Telegram).

## Как пользоваться

1. Создай **публичный** репозиторий на GitHub и загрузи в него все файлы из этой папки
   (включая `.github/workflows/build.yml` и `patches/`).
2. Получи свои `api_id` и `api_hash` на https://my.telegram.org (раздел API development tools).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
   Создай два секрета: `API_ID` и `API_HASH`.
4. Вкладка **Actions → Build IPA → Run workflow**. Дату оставь `2025-10-10`
   (Liquid Glass появился в версии 12.1 от 11 октября 2025).
5. Когда сборка закончится (может идти 1-2 часа), скачай архив `Telegram-ipa` из раздела Artifacts.
6. Установи `.ipa` на iPhone через Sideloadly или AltStore (они подпишут файл твоим Apple ID).

## Патчи (обложки профиля)

Положи файлы `*.patch` в папку `patches/`. Они применяются к исходникам Telegram перед сборкой.
Создать патч: внести правки в клоне Telegram-iOS и выполнить `git diff > cover.patch`.

## Если сборка упала

- Открой лог шага, который упал, и пришли мне последние ~50 строк.
- Частые причины: версия Xcode не совпала с `versions.json`, ошибка подписи (codesigning),
  в конфигурации не хватает полей.

## Название приложения

Название: **dzas0wGRAMM**, Bundle ID по умолчанию: `com.dzas0w.gramm`.
Шаг «Rename app» в workflow пытается подменить имя автоматически и печатает в логе, что нашёл.
Если на телефоне имя осталось «Telegram», его можно поменять в Sideloadly (поле Bundle ID / имя при установке)
или напиши мне, я поправлю шаг по логу.

Иконку тоже нужно заменить на свою: стандартный логотип Telegram (бумажный самолётик в синем круге)
использовать в форках нельзя.

## Анимированная заставка запуска

Файл `splash/SplashAnimationView.swift` содержит заставку: чёрный фон,
иконка-цветок рисуется линией, буквы dzas0wGRAMM выезжают по очереди, затем всё растворяется (около 3,7 секунды).

Подключение (после первой успешной сборки, когда будет видно, где в коде Telegram стартует окно):

```swift
let splash = SplashAnimationView(frame: window.bounds)
window.addSubview(splash)
splash.start()
```

Файл пока лежит отдельно и в сборку НЕ подключён, чтобы он не сломал первую сборку.
Он не компилировался и не проверялся на устройстве. Подключение (копирование в нужную папку,
запись в Bazel BUILD, вызов в AppDelegate) оформим патчем в `patches/`.
